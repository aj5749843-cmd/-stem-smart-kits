# معامل STEM الذكية · SMART STEM KITS LAB

معمل افتراضي ثلاثي الأبعاد يضم سبع حقائب ذكية على رف داخل غرفة معمل. تُفتح كل حقيبة على طاولة عمل يبني عليها الطالب مشاريعها: ينقل الحساسات والمشغّلات من الحقيبة، ويصلها بلوحة التحكم ESP32، ويبرمج قواعد «إذا… فإنّ…»، ثم يشغّل المحاكاة ويرى مجسّم المشروع يتفاعل.

**رابط الموقع:** https://aj5749843-cmd.github.io/-stem-smart-kits/

## الحقائب

| الحقيبة | المشاريع |
|---|---|
| SMART CITY KIT · المدينة الذكية | إنارة الشوارع، بوابة الموقف، إشارة المشاة، مراقبة الضوضاء |
| SMART CLIMATE KIT · المناخ الذكي | محطة الطقس، التبريد التلقائي، إنذار جودة الهواء، نافذة المطر |
| SMART HEALTH KIT · الصحة الذكية | مراقب النبض، كاشف الحمّى، سوار كشف السقوط، زر الطوارئ |
| SMART AGRICULTURE KIT · الزراعة الذكية | الري الذكي، إضاءة النمو، تهوية البيت المحمي، إنذار الخزان |
| SMART HOME KIT · المنزل الذكي | الإنارة بالحركة، إنذار الحريق، كاشف تسرّب الغاز، الباب الذكي |
| SMART SCIENCE IOT KIT · العلوم وإنترنت الأشياء | محطة رصد سحابية، كاشف المغناطيس، مقياس المسافة، مسجّل الضوء |
| ROBOTIC ARM KIT · الذراع الروبوتية | نقل المكعب، الفرز بالألوان، الذراع المبرمَجة |

## التشغيل

الموقع ملف واحد `index.html` يعمل في المتصفح مباشرة، ويحمّل مكتبة Three.js من شبكة CDN. يُحفظ تقدّم الطالب في متصفحه فقط.

## داخل كل حقيبة

- طاولة عمل ثلاثية الأبعاد عليها القطع ولوحة ESP32 وأسلاك التوصيل
- محرر قواعد برمجية بصيغة «إذا… فإنّ…»
- مجسّم مصغّر لكل مشروع يتفاعل مع قراءات الحساسات
- لوحة قراءات حيّة وشاشة مراقبة تسلسلية
- كود Arduino يُولَّد تلقائياً من بناء الطالب
